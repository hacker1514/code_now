## 🌟 Overview

**Code Now IDE** (NextLeet) is an advanced, high-performance web-based code editor, LeetCode problem prep platform, and AI-assisted debugging suite designed for software engineers, competitive programmers, and interview candidates.

Developed under **KNI (Knowledge Network Infrastructure)** by **Niranjan Kumar K**, Code Now combines a rich **Monaco Editor** interface, Judge0 multi-language execution engine, curated company tagged interview problems, system design study modules, and an integrated **Code Now AI Assistant**.

---

## 🔥 Key Features

### 💻 1. Multi-Language Code Playground
* **Monaco Editor Integration**: Full VS Code keybindings, bracket matching, line numbers, minification, word wrap, tab sizing, and customizable themes (Pure Black, Midnight, Dark/Light).
* **Multi-Language Support**: Execution support for Python, JavaScript, C++, Java, C#, Go, Rust, Haskell, and more.
* **Judge0 Compiler Backend**: Instant compilation, custom `stdin` input, stdout capture, execution time, and memory usage metrics.

### 🤖 2. Code Now AI Assistant
* **Smart Code Analysis**: 1-click instant diagnosis of syntax bugs, logic flaws, time/space complexity (Big-O analysis), and performance optimizations.
* **Rich Markdown Formatting**: AI replies render formatted markdown headers, bold emphasis, bullet points, and code block cards with syntax highlighting.
* **1-Click Apply to Editor**: Code snippets generated by AI can be applied directly to the Monaco editor with a single click.
* **Copy Code Snippets**: Quick 1-click code copying and message clipboard tools.
* **High-Speed Performance Context**: AI payload is optimized to process the last 5 relevant chat messages for ultra-fast response times.

### 🎯 3. Company-wise Problem Practice
* **Company Tags**: Practice interview questions tagged by top tech companies including **Google, Amazon, Microsoft, Meta, Apple, Uber**, and more.
* **Topic & Difficulty Filters**: Filter problems by topic (Arrays, Graphs, Dynamic Programming, System Design) and difficulty (Easy, Medium, Hard).

### 📐 4. System Design Notes & Insights
* **Interactive Design Guides**: Comprehensive notes covering scalability, caching, load balancing, microservices, and database partitioning.
* **Visual Insights**: Architectural diagrams and real-world system design walkthroughs.

## 🚀 Getting Started

### Prerequisites
* **Node.js** (v18.0.0 or higher)
* **npm** or **yarn**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nikhilthakur8/NextLeet.git
   cd NextLeet
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
